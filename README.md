# Earthrise

A lunar landing site navigator for the Moon's south pole, built for the
[NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/lunar-landing-site-navigator/).

Work in progress. See [JOURNAL.md](JOURNAL.md) for the current state.

## Layout

- `app/` the web app (Vite, React, TypeScript)
- `pipeline/` the Python reference model and the data build

## Use of AI

This project is built with AI assistance (Claude, by Anthropic). AI wrote most of
the code and documentation under the direction of the team. A full statement of
what was AI-made will be kept here and in the project submission.
